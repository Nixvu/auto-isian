# Auto Isian (Chrome Extension) - Official Release

Repositori resmi rilis dan pembaruan ekstensi browser **Auto Isian**.

## Cara Pasang Pembaruan (.CRX):
1. Unduh file `auto-isian.crx` terbaru dari tab [Releases](../../releases/latest).
2. Buka `chrome://extensions` di Google Chrome.
3. Aktifkan **Developer mode** (pojok kanan atas).
4. Tarik (*drag and drop*) file `.crx` ke dalam halaman ekstensi.
